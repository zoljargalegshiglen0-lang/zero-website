# WINGS V5 Monochrome Update

What changed:
- Overall visual theme shifted to a black / white monochrome direction.
- Sidebar, topbar, homepage panels, cards, buttons, stats blocks and admin panels were restyled.
- Monochrome logo asset added: `public/wings-mark-mono.svg`.
- Header, footer and homepage now use the monochrome mark.
- Skinchanger / admin / general site chrome received grayscale surface and control overrides.
- Bright accent-heavy gradients were reduced to cleaner neutral styling.

Goal:
A cleaner, less colorful, more minimal premium direction while keeping the existing structure and functionality.
