# WINGS CS2 Community

Vercel-ready Next.js project.

## Included
- WINGS redesign
- Discord Join buttons linked to `https://discord.gg/tFNYKQpHZe`
- Admin login
- Admin website controls
- Staff manager
- Homepage cards / announcement / server widget defaults
- Steam / CS2 bridge hooks

## Fast update flow
After editing files locally:

```powershell
git add .
git commit -m "Update website"
git push
```

If the repository is connected to Vercel, a push to `main` automatically starts a new deployment.

See `VERCEL_DEPLOY.md` for first-time setup.
