WINGS v12 sticker studio upgrade

New sticker workflow
- Pick a sticker slot.
- Click any sticker from the accessory catalog.
- The preview enters STICKER MODE.
- Click anywhere on the weapon model to place the sticker.
- Drag placed stickers to reposition them.
- Use rotate and size controls for fine-tuning.

Visual upgrades
- Larger 3D demo preview area.
- Bigger weapon model preview.
- Added zoom slider.
- Clear placement hint banner.
- Accessory/sticker cards made cleaner and easier to browse.
- Better modal proportions for sticker crafting.

Goal
- Closer to CS2-style sticker application behavior while staying as a web demo.
- Still ready for API/loadout saving and external plugin bridge integration.
