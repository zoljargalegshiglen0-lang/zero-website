WINGS exact CS2 model loader

Place licensed/exported GLB models in this folder using lowercase weapon slugs.
Examples:
  ak-47.glb
  m4a1-s.glb
  awp.glb
  usp-s.glb
  desert-eagle.glb
  knife.glb

The skinchanger automatically tries /models/cs2/<weapon-slug>.glb.
If a GLB is missing, the website falls back to the catalog weapon image.

Important: exact in-game geometry cannot be bundled here unless you provide models you are allowed to use/distribute.
